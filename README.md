Entry for the [Rejected Olympic Sports](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on make.fun — one funny single-line sport the Olympics rejected, judged pairwise by a house judge.

## The entry

> Competitive pretending to listen: athletes nod for four hours while their partners talk; the first to say 'huh?' is disqualified.

129 characters. A made-up event, real enough to sound like a broadcast, absurd enough to be funny: four hours of nodding, and one honest "huh?" ends your Olympic dream.

## How it works

`main.py` (Python standard library only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written, no network is used, and the program runs in a bare sandbox as user `nobody` against a read-only copy of this repository.
